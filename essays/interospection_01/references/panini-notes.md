# Pāṇini notes (standing)

Standing preferences for morphological debate. Not a sūtra corpus.

## Method (v1)

- Separate **form** (prakriyā), **lexicon** (dictionary sense), and **prayoga** (essay use).
- Prefer traditional categories: dhātu, pratyaya, vibhakti, samāsa type, kṛdanta vs taddhita.
- Cite sūtra numbers/names only when confident; never invent IDs.
- Mark uncertainty explicitly.
- Settle useful analyses into `lexicons/glossary.md` (`dhatu`, `analysis`, `sense_source`).
