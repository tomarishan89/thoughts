# Catalog of Lenses

**Purpose:** A living record of conceptual perspectives (lenses) discovered during framework development. Each lens is a specific interpretive frame that, when applied to a new domain, reveals structure invisible from other perspectives.

**Convention:** Lenses are numbered L1, L2, ... in order of discovery.

---

## L1: The Horizon Lens
**Discovery:** §6.6 (Membrane Paradigm) — the cosmological horizon as a stretched membrane.
**What it does:** Treats any boundary $\partial E$ as a horizon with surface tension, viscosity, and Hawking-like temperature. Asks: "what are the quasi-normal modes? What Hawking-like radiation does it emit? What does the no-hair theorem erase?"
**Applied to:**
- Cosmological horizon → $\Lambda$ as Young-Laplace pressure (Prediction #1)
- BH event horizons → echo prediction (§7.5.4, brainstorming Thread 1)
- Ion channels → biological horizons (§7.5.4)

## L2: The Engine Lens
**Discovery:** §6.7 (4-Phase Cosmic Engine Cycle)
**What it does:** Decomposes any persistent process into 4 phases: fuel intake → work extraction → waste exhaust → reset. Asks: "what is the fuel? What is the work product? What is the waste? What is the efficiency?"
**Applied to:**
- Cosmic evolution → CMB as exhaust (ISSUE-4.53)
- Stellar nucleosynthesis → mass-energy conversion
- Cellular metabolism → ATP cycle
- Neuron firing → action potential cycle (§7.5.3)

## How to Use This Catalog

When approaching a new problem or domain:
1. **Scan all lenses** — systematically ask each lens's question
2. **Look for isomorphisms** — which lenses reveal the same structure at a new scale?
3. **Log new lenses** — if the problem requires a perspective not in this catalog, add it
4. **Combine lenses** — the most powerful insights come from applying 2+ lenses simultaneously (e.g., L6 + L2 = biological horizon + engine cycle → action potential as a horizon-crossing engine)
